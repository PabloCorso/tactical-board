# Issue tracker: GitHub

Issues and PRDs live in this repository's GitHub Issues. Use the `gh` CLI from
inside the clone so it infers the repository from the remote.

Use `gh issue` to create, view, list, comment on, label, and close issues. Include
comments and labels when gathering issue context.

"Publish to the issue tracker" means create a GitHub issue. "Fetch the relevant
ticket" means view the issue with its comments and labels.
